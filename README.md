## Featured Project: Roster

Roster is a course-planning prototype developed with two teammates at the Lehigh Fall 2026 Collegiate Hackathon. It brings course materials, professor reviews, workload estimates, and friends’ schedules into one place.

**My contributions**
- Proposed the idea and helped the team agree on the project direction.
- Co-designed the interface and features.
- Used Microsoft Copilot, OpenAI Codex, and Google Gemini to prototype features, test functionality, and refine layouts.

**Project stack:** React, TypeScript, CSS, Vite, Vinext

The prototype uses sample data, with temporary accounts and uploads stored in browser memory.
